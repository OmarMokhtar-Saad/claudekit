## Goal
Delete the ops.json engine and everything that only exists to feed it. After this plan `plan-gate` + `checkpoint-gate` + `shell-write-gate` are the only edit gates, the main session edits directly, and a repo-wide grep for the engine names returns zero hits outside CHANGELOG and history files.

## Approach: three slices, each a commit, each leaves its own tests green
Reviewer round 1 (72, REVISE): the old 2a was not atomic and Files: was incomplete. Fixed: engine, CLI, evals, scripts, agents, skills and ALL tests that touch them move together in slice A.

### A. Engine, CLI, hooks, agents, skills, evals and their tests (one commit)
Delete the engine scripts, `iron-law-gate.py`, `implementer.md`, the three ops skills (both trees) and the ops tests. Edit every caller in the same commit: hooks, `review-record.py` (plan key only), `cli/main.py` verbs, `cli/flow.py`, `eventlog.py`, `context_floor.py`, `profiles.py` GUARDED_HOOKS, `dispatch-registry.json`, `minimal/profile.json`, `run-evals.py`, `check-plan-artifacts.py`, `gen-plan-index.py`, `check-protected-differential.py`, `fleet-sync.sh`, `ci.yml`, `.gitignore`. MAX_DELETIONS code in shared.py, worktree-manager.py, repo-hygiene.py and check-protected-differential.py goes with the engine; checkpoint-gate is the safety net. Agent, command and skill prose: ops.json / implementer wording becomes plan + direct edit. Evals: delete implementer-no-fabrication, rewrite the other two. Regenerate with gen-registry, gen-model-policy, gen-agents-mirror, gen-docs; add a removed entry for implementer in skills-registry.json. Run only the touched test files plus structure and doctor.

### B. Docs and governance
README, docs/, i18n/, examples/, .claude/local templates, CONTRIBUTING, `.ai/` non-history docs, CHANGELOG [Unreleased]. Exempt and not edited: older CHANGELOG entries, CHANGELOG_AI, SESSION_STATE, BACKLOG, DECISIONS, STATUS, review/, .claude/reports, .claude/plans/archive, `.claude/plans/ops-*.json` (archived payloads), knowledge/rejections, agent-memory, `.claude/.claudekit-history.json` (regenerated), `.claude/plans/plan-*.md` (historical plans, except this plan and its parent), `.claude/plans/phase-*`, `.claude/plans/ops-*`, `.claude/plans/payloads/**`, `.claude/plans/INDEX.md` (regenerated by gen-plan-index), `.claude/knowledge/heldout/**` (snapshot data). `.claude/knowledge/proposals/README.md` is live prose and is edited in B. Rule 4 in CLAUDE.md/AGENTS.md waits for the owner: between A and the owner's pick the text says MAX_DELETIONS=3 while the code is gone; no test asserts that text (checked before A), and checkpoint-gate covers the interim. After A alone, `gen-docs --check` and test_structure must be green; slice A regenerates counts.

### C. Gate
Grep criterion: zero hits outside the exempt set above, this plan and its parent plan-remove-ops-main-session.md (they name the engine by design), untracked runtime/build artifacts (`.claude/hooks/*.log`, sync-conflict logs, `src/*.egg-info/`), and `.claude/settings.local.json` (skillOverrides for the three removed skills: owner-only edit, listed as an owner step in the hand-off). One full-suite run in the background (about 27 min), fix Phase-2 failures only, `ck doctor --strict` 100/100.
