# Archived ops configs

Ops configs whose anchors no longer match HEAD live here. `tests/test_delivery_contract_smoke.py::test_queued_ops_configs_validate_against_head` gates the parent directory: a queued (non-archived) ops config that fails `validate-config-json.py` fails the suite, so stale plans get caught mechanically instead of at execution time.

Move a config here when it is **spent** (already executed — anchors consumed by its own edits) or **stale** (the target files changed underneath it — regenerate via `/plan` before executing).

| `ops-fleet-enhance.json`, `ops-enhance-mypy.json`, `ops-enhance-types*.json` | Spent — executed 2026-08-25. `fleet-enhance.py`: brings every kitted repo to the current corpus **without reinstalling**. The reason it exists is measured, not stylistic — `install.sh --force` refreshes by moving `.claude/` aside and restoring what it can guess, and on a project with **no** `.claudekit-manifest.json` that guess is a directory heuristic (`agents/`, `commands/`, `skills/` only). **rest-framework is the fleet's only un-manifested repo**, so a reinstall would have stranded 5 named files in the backup: two project-specific hooks, its own plan, and `rules/repository-flow.md` — `rules/` being a directory concept the kit has no notion of at all. Instead: additive, non-destructive, and **exact where a manifest exists**, because the manifest records sha256 per installed file. A file is UPDATED only when its current hash still matches what the kit installed (nobody touched it); edited files are reported and left alone; local files are never considered. Without a manifest it degrades honestly — ADDs what is missing and **refuses to update anything**, because it cannot prove a file is pristine and guessing is the failure it exists to avoid. Result: **303 added, 802 updated, 202 preserved, 0 deleted, nothing moved aside**, all 13 repos at zero missing assets; rest-framework went 34 → 84 skills and 14 → 56 commands with all 5 at-risk files intact. Idempotent (re-run reports 0/0). Proven before the fleet run on a scratch copy with a planted local skill, a planted `plans/` file and a deliberately customised kit file — all three survived, 218 → 235 files, purely additive. |
