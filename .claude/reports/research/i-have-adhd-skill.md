### Purpose
Restructures Claude Code responses to prioritize actionable information, preventing important answers from getting buried in lengthy explanations. Built for ADHD accessibility but widely adopted because most people prefer this output format.

### Key Instructions (10 Rules)
1. Begin with immediate next action
2. Use numbered steps for multi-step processes
3. Conclude with one specific next step
4. Avoid tangential information
5. Restate current state each turn
6. Provide concrete time estimates
7. Highlight accomplishments
8. Present errors matter-of-factly
9. Limit lists to 5 items maximum
10. "No preamble. No recap. No closers."

### Core Technique
Transforms verbose AI responses into action-oriented, directive, scannable output format.

### Installation
- Copy CLI command into your prompt, or
- Reference INSTALL.md for detailed setup
- Compatible with Claude Code and other agent platforms
